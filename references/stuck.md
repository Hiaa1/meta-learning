# 模式 C:卡住了

用在对方说"我查了半天查不出来""每一步看着都对但结果就是不对""改了好几版还是老样子"的时候。

这个模式**不解释概念**,只做定位。核心判断是:问题在**基底之上**,还是**基底本身画错了**。

## 第一步:分诊

先问一句,只问这一句:

> 你现在的症状是「某处对不上/矛盾」,还是「每层都自洽,但就是不 work」?

- **有矛盾** → 问题可定位,在基底之上。正常往下查,这个模式到此结束。
- **处处自洽却不 work** → **这是基底把 bug 关在里面了的特征签名。** 继续下面的步骤。

区别很关键:找到矛盾意味着错误已经暴露在你正在看的范围内;毫无矛盾意味着错误在你**按构造看不见**的地方。后者你怎么查上层都查不出来,因为它根本不在上层。

## 第二步:调试方向——先横后纵

自洽而不 work 时,默认动作应该是**横向挪边界**,不是纵向再挖一层。

这是这套心法的主要副作用需要的解药:"往下挖到第一性原理"会系统性地把注意力从最常见的故障类型上引开。真实故障的分布里横向占多数。

按这个顺序列出**当前被默认当成对的东西**,逐个点名:

1. **目标本身写错了**(reward / loss / 优化的到底是不是你想要的那个量)
2. **测量错了**(评测协议、指标、日志本身在骗你)
3. **数据/环境错了**(管道、泄漏、特权信息、提前终止、单位、坐标系)
4. **推导错了**(你以为基底蕴含这个结论,其实不蕴含)
5. **基底本身不适用**(成立条件在这个场景被违反了)

前三项是横向的,而且是自洽型故障的主要来源。**别从第 5 项开始查。**

## 第三步:补丁计数

问:**同一个症状,已经打了几个补丁?**

- **≥ 3** → 强制基底复审,**禁止打第四个补丁**。

这条规则必须是硬的,因为自然动力学永远倾向于打第四个补丁:你在基底上盖得越多,重开的代价越高,而怪辅助假设永远更便宜。触发条件不会自己发生,要靠计数强制。

## 第四步:进步还是退化

问:**最近这几个补丁,除了解释已经看到的这次失败,有没有顺带预言过一件你还没看到的事?**

- **有** → 进步的,继续。
- **全是追认** → 退化的。**只会追认、不会预言的补丁串,就是基底该换了的信号。**

历史上的原型对照:

- 天王星轨道偏离牛顿预测 → 怪辅助假设(行星清单不全) → 预言"某个具体位置有个新天体" → 找到海王星。**进步的。**
- 水星近日点偏离牛顿预测 → 同样怪辅助假设 → 预言祝融星 → 不存在,后来不断调整这颗看不见的星的参数去吻合新数据。**退化的。**真正错的是基底,需要广义相对论。

**两次的失败征兆完全一样,正确反应完全相反。**

## 第五步:靠图案定位,不靠单次失败

这是最容易被跳过、也最要命的一步。

**单次失败只牵连整个前提集,定位不了任何东西。** 你从来不是单独检验基底,你检验的是 基底 + 一堆辅助假设 + 你的推导 + 你的测量。后果为假,逻辑只告诉你"这里面至少有一个错",不告诉你是哪个。一次失败给你一个 bit,你有二十个候选。

所以定位的做法是:

> 从当前基底往**不同方向**推出 3~5 个后果,一起测,看**失败的图案**。

- 五条里四条中、一条不中 → 责任集中在那一条特有的辅助假设上。
- 五条全不中 → 责任集中在基底。

**这一步无法用"更仔细地看那一次失败"替代。**信息量不在那儿。

## 输出格式

模式 C 的输出是一份定位报告,不是解释:

```
症状类型:   矛盾型 / 自洽型
当前隐含基底:(逐条列出被默认当成对的东西)
最可疑的三项:(按横向优先排序,给出为什么可疑)
补丁计数:   N —— 是否触发强制复审
进步/退化:  最近的修补有没有预言过新东西
下一步:     要推出的 3~5 个不同方向的后果,以及各自怎么测
```

不要在这个模式里顺手讲概念。对方卡住的时候,多讲一层只会增加候选集。
