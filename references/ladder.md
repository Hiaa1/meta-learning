# 阶梯:L0–L5,以及怎么在上面推进

两个模式共用这个文件:

- **模式 B(规划)**——对方说"我想学 X""帮我入门 X""怎么系统地搞懂 X"。产出是一条**分级路径**,不是书单,也不是知识点清单。
- **模式 D(推进)**——每一格结束后,决定下一步动哪儿。判据在下面每一级的「升级判据」里。

**B 只画路线,D 一格一格地走。** 规划出来的路径是给对方看的地图,不是执行计划——不要在给出路径之后顺手开始走第一格。给完路径就停,等他动手。

路径本身也要按「一次只推进一格」交付:告诉他**下一格是什么、怎么判断这一格走完了**,后面几格只列标题,不展开内容。

## 阶梯的形状

六级的动作动词各不相同:**认 → 画 → 封 → 摸 → 换 → 挪**。

每一级的方法必须不同,不能是同一件事做得更深。原因是专长反转效应(expertise reversal effect):对新手最优的高约束方式,对专家是枷锁;对专家最优的自主生成,对新手是灾难。把同一套方法套在所有级别上,是这类心法最常见的失败。

**L0 是最容易被整个跳过的一级**,因为跳过它的代价对解释者不可见:你自己早就过了 L0,那些前提在你这儿已经不算知识了。跳过的症状很具体——**对方盯着一张结构图,每个框都认得字,但一个框都想象不出实物**。

---

### L0 认 —— 你还不知道这是什么

- **基底**:没有,而且你连"该问什么"都不知道。这一级的任务不是理解,是**能想象**。
- **动作**:四件事,**顺序不能反**——
  1. **先实例,后抽象。** 至少给两个对方真见过的具体东西。抽象结构在没有实例可挂的时候,读起来只是一串陌生名词。
  2. **问题。** 朴素做法为什么不行——这一步回答"这个领域为什么存在"。**它必须排在结构之前**,否则后面所有的复杂度看起来都像是凭空冒出来的。
  3. **黑箱接口。** 整个东西的输入是什么、输出是什么。**不打开箱子。**
  4. **最小词汇表。** 只给**读下一格所必需**的词,一个不多。不是"这个领域的常用术语表"。

**L0 的核心手法是"让问题长出结构",不是"给出结构再解释"。** 理想形态:对方读完第 2 步,自己就已经隐约看见下一格那张全局图的形状了——因为每一格都对应问题里的一个坎。做到这一点,L1 就不是新信息,是确认。

**L0 是最该用结构性比喻的一级**,因为对方手上还没有任何本领域的东西可以挂。选比喻的判据和标注要求见 `SKILL.md` 的「比喻」一节——**用了就必须同时说出它断在哪**,尤其是"源域里免费、目标域里最贵"的那件事。
- **错了的样子**:听到一个名词,想象不出任何具体东西;或者能复述定义,但举不出例子。
- **升级判据**:能举一个具体实例,并说出整个东西的输入和输出。

**这一级不画全局图。** 全局图是 L1,它需要 L0 的词汇才读得动。

### L1 画 —— 你还不知道全局长什么样

- **基底**:L0 那个黑箱,现在要打开,但只看**分块**,不看块内。
- **动作(自学)**:不读教科书。**找一个能跑的仓库,跟着一条执行路径从入口走到出口**,把路上经过的模块画成一张图。补充材料是三篇综述的 Figure 1。目标是拿到**本体论**(有哪些格子、谁连谁、每条线上传什么),不是知识。
- **动作(讲给别人)**:见 `SKILL.md` 的「L1:画全局图」——三道检查,一道都不能省。
- **陷阱**:上面那个自学动作走出来的是**实现的图**,不是**对象的图**。前者是"跑这个东西的那个程序"长什么样,后者是"这个东西本身"长什么样。自学时前者够用,它让你认门;**交付给别人之前必须过换主题测试**,否则你讲的是容器。
- **错了的样子**:遇到一个名词,说不出它属于图上哪一格。
- **升级判据**:两条——能画出全局图并指着其中一条线说"我封在这里";**能把自己见过的三个现象分别落到图上某一格**。

### L2 封 —— 在基底之上产出

- **基底**:领域共识接口。直接接受,不问为什么成立。
- **动作**:**端到端做出一个完整的、粗糙的东西**。然后进入循环:改一个变量 → **先写下预测** → 跑 → 对账。
- **注意**:这是整个阶梯里唯一一个"照着做就行"的阶段,也是大多数人应该长期停留的阶段,**不是失败状态**。
- **错了的样子**:结果不对,而且修复动作全部落在基底之上(你能改的东西里)。这是**正常**的,不构成升级信号。
- **升级判据**:两条同时满足——(a) 能预测基底之上常规改动的结果("加大这个权重会发生什么");(b) 别扭日志里有存货。

### L3 摸 —— 把基底的边界摸出来

- **基底**:同一个,但现在它变成了**研究对象**。
- **动作**:补齐基底卡的后两段(成立条件、失效征兆)。三个来源:
  1. 往下懂一层,**只一层**;
  2. **主动去问人**——失效模式是默会知识,文献里不写,存在于代码注释、失败实验和一次面对面的对话里;
  3. 用历史当手术刀,只问一个问题:"这个接口为什么切在这儿",答案通常是某个东西当年很贵。
- **错了的样子**:**处处自洽,但就是不 work。** 这是基底出问题的特征签名,不是上层还没查够的签名。
- **升级判据**:拿到一个**新**问题,能**事前**说出"这个会踩到基底的哪条失效模式"。事前,不是事后解释。

### L4 换 —— 基底不止一个

- **基底**:两到三个可选基底,以及它们之间的映射。
- **动作**:按**失效模式**数基底,不按形式差异数。
  - 值得:牛顿 / 拉格朗日(一个告诉你力从哪来,一个处理约束并推广到场论);卡尔曼滤波的贝叶斯视角 / 最小二乘视角(一个告诉你噪声非高斯时怎样,一个告诉你病态时怎样)。
  - 不值得:同一个目标函数的十种写法。同样的失效模式,零新外推方向。
- **映射是买不到的那部分。** 教科书只讲一组基,"这一项对应那个力"靠自己接。这一层的全部价值在映射上。
- **错了的样子**:换了基底,难问题没有变容易。说明映射是背下来的,不是通的。
- **升级判据**:有过至少一次**换基底把死问题变显然**的实例。

### L5 挪 —— 接口本身可以移动

- **基底**:领域共识的切法,现在也成了对象。
- **动作**:识别"共识接口对这一类问题切错了位置"。历史第二次上场,问法变成:**接下来什么在变便宜?**
- **提醒**:范式转变常常是**零概念变化**的纯成本坍塌——深度学习压过 SVM 时,反向传播已经存在二十年了。所以只盯概念空白会漏掉下一次转变。
- **错了的样子**:新切法只能追认已经看到的现象,不能预言任何一件还没看到的事。那是退化,不是进步。
- **升级判据**:没有出口。这里就是前沿。

## 三个常设物件

贯穿所有层,建议就是三个纯文本文件。

### 1. 基底卡

每个基底一张,三段:

```
内容:  一句话,这次把什么当成对的
条件:  它在什么范围内成立
征兆:  被违反时你会观察到什么现象
```

共识接口白送第一段,后两段自己挣。**决定你会不会被烧到的是后两段。**

### 2. 别扭日志

每次基底逼你加例外、说一句绕的话、承认"就是这样",记一行。

**这是唯一会自己响的升级触发器。** "等我足够了解了再回头看基底"这个触发器永远不响,因为基底越好用越隐形——它工作得越好,你越不可能想起它是个选择。会响的信号不是理解量,是**摩擦**,而摩擦按它自己的时间表到。

**但触发 ≠ 放行。别扭触发的是复查,升级判据才是闸门。**

- 好奇("下一层是什么")——不是别扭,不复查。
- 别扭("我得给它加第三个例外了""这里我只能说'就是这样'")——开始复查。
- 复查时对照本级的升级判据。**判据不满足就明说不满足、缺哪一条、怎么补。**

跳过判据往下讲的代价是具体的:他会变成听得懂、但干不了活。这个状态比停在 L2 差,因为它还额外让人误以为自己已经过关了。

### 3. 预测记录

跑之前写下预期,跑完对账,记下对不上的地方。

领域史只告诉你**领域**错在哪;这个才告诉你**你**错在哪。两者不重合——你的压缩可以以领域从未犯过的方式出错,因为你的错误是特异的。

## 深度怎么分配

**轴不是半衰期,是「半衰期 × 静默失败代价」。**

- **响亮失败**(报错、崩溃、编译不过):停在 L2 就够。框架 API、配置字段属于这类,错了会立刻叫。
- **静默失败**(照跑不误,结果悄悄是错的):**不管半衰期多短都要推到 L3**。仿真的接触参数、评测协议、数据管道属于这类。

半衰期本身的三个事前判据:

1. **它被物理/数学约束,还是被委员会约束?** 前者长,后者短。这一条能分掉大部分案例。
2. **被独立重新发现过几次?** 同一个东西以多个名字在不同传统里出现,说明它在解空间的不动点上。
3. **换掉底层基质还活着吗?** 反向传播扛过了 CPU→GPU→TPU;特定 kernel 技巧没扛过。

粗糙兜底:Lindy——预期剩余寿命 ∝ 现有年龄。

## 关于"完整了解一个领域"

**阶梯是按主题走的,不是按领域走的。** 一个领域不可能、也不该把所有东西推到 L5。

健康分布大致是:**两三个主题在 L4/L5,十几个在 L3,其余全在 L2。**

所以"完整了解"的正确定义不是每样都挖到底,而是:**全局图完整 + 深度分配正确 + 每个基底都知道自己什么时候会失效。** 能诚实说出"这块我停在 L2,它的失效征兆是什么,踩到了我会知道"——这比假装都懂完整得多。

## 这套东西的成本

它买的是**迁移能力**和**不被自己骗**,卖的是**速度**。

做研究划算;赶交付不划算,那时候正确动作是全部停在 L2。规划路径时要把这句话告诉对方,不要默认所有人都该走完六级。
